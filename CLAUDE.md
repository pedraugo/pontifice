# PONTIFICE

## Comments

- Add a comment only when necessary: when what the code does is not clear or explicit from the code itself.
- When a comment is needed, keep it on a single line, between 2 and 20 words.
- Prefer code free of comments when generated by Claude.
- Write comments in English.

## File naming

- Files in `src/**`, `docs/*`, `tests/*` and `tools/*` are camelCase (`battleScene.cpp`, `translate.json`, `cardBack.webp`, `deckTest.cpp`, `makeIcons.py`); folders are lowercase.
- Numbered music tracks keep the numeric prefix and camelCase the rest (`1.fastBattle.ogg`).
- Rename with `git mv` so case-only renames are recorded in the index (macOS file system is case-insensitive).

## Logging

- Use `LOG(format, ...)` from `scripts/log/log.h`; never `SDL_Log`, `printf` or `fprintf` for logs.
- Line format: `[YYYY-MM-DD HH:MM:SS] [filename] - message`. Messages in English, no trailing newline.
